# Heading Guard · 设置说明

想细调规则时看这份。第一次用请先看 [`../README.md`](../README.md)。

## 行为说明

打开自动编号后，标题会按你的规则编号：

- **什么时候会编号**：切到某篇笔记后 2 秒、停止输入约 1 秒各会立刻编号一次；此外按你设的检测间隔兜底复查，而且**只有当标题真的变了才动手**（先比标题签名：等级 + 顺序 + 内容）。
- **光标停在标题行时不编号**：光标所在的那一行正好是标题 → 这一轮整体跳过，等光标移开再编。
  这么设计是为了不打断「正在敲标题」的那一刻。手动命令和刚切进笔记不受影响。
- **幂等**：已经编好号的笔记反复触发也不会有任何变化，更不会叠成 `1 1 标题`。
- **一次撤销**：所有改动在**一个**编辑事务里提交，按一次 `Ctrl+Z` 就能整体回退。
- **链接跟着走**：编号变化时，全库指向该标题的 `[[笔记#旧标题]]` / `[文字](笔记.md#旧标题)` 会一起改掉，和 Obsidian 官方「重命名小标题」的效果一致。
- **不碰代码块**：标题从 Obsidian 的标题缓存里取，所以围栏代码块、缩进代码块里的 `#` 一律不算标题。
- **认得出旧编号**：`### 2.1 语言` 会按新规则被替换成 `### 1.1 语言`，而不是叠加。

## 设置项

### 语言

简体中文 / 繁體中文 / English。只影响插件的设置面板与提示语（切换后设置面板立即重绘；命令名称需要重载插件才更新）。

**首次安装时会自动识别 Obsidian 的界面语言**：中文 → 简体中文，繁中（含港/澳）→ 繁體中文，其它语言 → English。
一旦你自己在这个下拉里选过，就以你的选择为准，**不再被覆盖**。

### 开启自动编号

默认关闭 —— 装好不会动你的笔记，需要你主动打开。打开后按三层触发：切笔记 2 秒后 / 停止输入约 1 秒后 / 按检测间隔兜底复查。

### 检测间隔（在「开启自动编号」那一行上）

一个 5~60 秒的滑块（默认 10 秒），控制**兜底复查**的周期；它右边直接显示当前秒数，再右边是「重置」按钮（关闭自动编号并把间隔恢复成 10 秒）。自动编号关着时滑块不可用。

> 两次编号之间的实际间隔通常远小于这个值 —— 因为切笔记和停止输入都会立刻触发，滑块管的是「万一前两层都没捕捉到」的那条兜底通道。

> 拖动滑块时**不会**立刻写盘，停手约半秒才存一次；也不会顺手触发一次编号（只是改了复查周期，标题没变）。

### 自动编号的作用范围

`全部笔记`（默认）/ `仅声明过的笔记`。

- `全部笔记`：所有笔记都自动编号。
- `仅声明过的笔记`：只编在 frontmatter 里明确声明过的笔记，其余一律不动。想编的话在该笔记开头写：

  ```yaml
  ---
  heading-guard: on
  ---
  ```

**不管选哪个，frontmatter 里的声明都能覆盖作用范围**，判定顺序是先命中者胜：

| 顺序 | 条件 | 结果 |
| --- | --- | --- |
| 1 | frontmatter `heading-guard: off`（或 `false` / `no`） | **不编** |
| 2 | frontmatter `heading-guard: on`（或 `true` / `yes`） | **编**（无视排除文件夹） |
| 3 | 笔记路径命中「排除文件夹」 | **不编** |
| 4 | 其余 | 按作用范围（`全部笔记` 编 / `仅声明过的笔记` 不编） |

> **只影响自动编号。** 手动命令（「编号本文标题」/「重置标题编号」）**不看**这个设置 —— 你点了就执行。

### 排除文件夹

**每行一条**，比如：

```
Z-附件/Z1-笔记模板/
存档/
```

- 按**路径前缀**匹配：写 `notes/` 不会误伤 `notes2/`。
- 正斜杠 `/` 和反斜杠 `\` 都认，末尾的斜杠可有可无（插件内部统一成 `/` 结尾再比）。
- 首次启用这个功能时，如果本机装了核心插件「**模板**」并且设了模板文件夹，会**自动帮你填上**
  （模板文件通常不需要编号）。填错了直接删掉就行；没装「模板」插件就留空。

### 编号前尝试去除旧编号

**默认开启**（2026-09-28 起）。打开后，编号之前先把标题文字里残留的旧编号去掉 —— **从左往右认，一次剥干净**（不是「切一刀」）：

| 原来 | 结果 | 为什么 |
| --- | --- | --- |
| `1.2、 一级标题` | `一级标题` | 编号是 `1.2、`，空格只是分隔 |
| `1.2、一级标题` | `一级标题` | 编号到 `、` 结束 |
| `1、公共示例：` | `公共示例：` | 编号是 `1、`，不会去碰正文的 `：` |
| `1.1定义合法标识符规则` | `定义合法标识符规则` | 多段数字编号紧跟中文正文（中文笔记高频写法） |
| `a 六级标题` / `t10 - 获取实时行情` | `六级标题` / `获取实时行情` | 字母编号 |
| `4、5140 银行卡预制卡批量领卡` | `5140 银行卡预制卡批量领卡` | 编号只到 `4、`；`5140` 大于 20 属正文 |
| `3、78.21线` / `2.6 78.6位` | `78.21线` / `78.6位` | 同上：接续数字大于 20 不当作编号 |
| `IV. 讨论` / `II 标题` | `讨论` / `标题` | 规范罗马数字放行 |
| `XML. 说明` / `MAX 标题` | 不动 | 字母都在 `IVXLCDM` 里，但反算不成规范罗马数字 |
| `一级、标题` | 不动 | 认不出编号（编号后必须紧跟分隔或空白） |
| `2024 年度总结` | 不动 | 数字 **≥100 且大于本篇标题总数** → 不像编号 |
| `1 1、标签有：` | 不动 | 空格后面是数字 → 像数据列/编号写重，不是编号 |

**保留的校验**（认成编号之后再过一遍）：不含「一…九、壹…玖、十拾百仟」之外的中文；不含连续两个英文字母
—— **除非**那串字母是规范罗马数字；数字不超过 100 的阈值判定见下面那行；剥完不能什么都不剩。

> **「≥100 且大于本篇标题总数」怎么判的**：编号部分里如果出现比本篇标题总数还大的数字，就认定它不是编号。
> 因此 `# 2024 年度总结`、`453  Shelvin Mack` 这类会保持原样；
> 而笔记里标题够多时，`120、第六十节`（本篇有 200 个标题）仍会照常清理。
> 阈值取 100 是实测比对过五个方案后的结论：只拦两位数字会误伤 `t10` 这类序号，
> 只看位数不看总数会一口气拦住 73 条无辜的两位序号。

> **「接续数字 > 20 不算编号」怎么判的**：编号段之后再出现一个**大于 20** 的连续数字，就认为它属于正文
> （业务数值、卡号 BIN、页码都在这个量级），编号到此为止。
> 真编号的**层级后缀**都很小（`4.1-10 支付数据对账` 的 `10`、`1.2-1 安装WSL` 的 `1`），不受影响。

**它和「重置当前笔记标题编号」是同一套算法、同一份实现**（见下面「重置标题编号」一节），两条路径只是入口不同。

### 子标题是否继承父标题的跳过注释

**默认关闭。** 打开后，带 `%%skip%%` 的标题，**它下面的整棵子树也一起跳过** —— 不编号、不占号，直到出现等级**不深于**那个标记标题的标题为止：

```md
# 1、一级标题
## 二级标题
%%skip%%
### 三级标题        ← 继承跳过
### 三级标题        ← 继承跳过
## 1.1 二级标题     ← 兄弟标题不受影响，照常编号
### 1.1.1 三级标题  ← 它的子树也照常编号
# 2、一级标题
```

同一行后面还有一个下拉框：`不删除旧编号`（默认）/ `尝试删除旧编号`。选后者时，**这一整块**（含带 `%%skip%%` 的那一行**自己**）会顺手把旧编号删掉（只删、不写新编号）。

**默认的 `不删除旧编号` 下**，带 `%%skip%%` 的那一行**完全不动**（不改、不删原有编号）—— 这也是 `%%skip%%` 当「别碰这一行」的逃生口时的本意。

### 全局编号尾缀

一行两个控件：**尾缀字符（下拉框）** + **尾缀后是否加空格（下拉框）**。

「分隔符」就是编号与标题内容之间那个字符：不用全局尾缀时它就是**一个空格**，用了就是所选的尾缀字符（可再跟一个空格）。

| 尾缀字符 | 尾缀后空格 | 效果 |
| --- | --- | --- |
| `无` | — | `# 1 一级标题` |
| `、` | 加空格 | `# 1、 一级标题` |
| `、` | 不加空格 | `# 1、一级标题` |

尾缀字符**只能从锁定列表里选**：`无` `、` `.` `-` `_` `)` `>` `」`。

> 1.4.7 起去掉了 `.` `·` `;` 三个符号，1.5.0 又去掉了 `:` `~`；随后按用户要求把 `.` 加了回来（排在 `、` 后面），再去掉了 `』` `】`。
> 存量设置里如果有表外符号，加载时会自动回落到 `无`（不需要你手动改）。

选 `无` 就等于**不用全局尾缀** —— 这一项**没有单独的开关**，下拉框本身就是开关。此时一至六级标题各自的尾缀设置说了算。选了任何一个符号，全局尾缀立刻覆盖一至六级，各级的尾缀控件（**开关也一起**）随之变为不可编辑。

### 样式预览

只读的预览框，把固定的六行样例（`# 一级标题` 到 `###### 六级标题`）按当前规则跑一遍，**改任何设置都会立刻刷新**，用来确认规则改对了没有。

### 一级标题 ~ 六级标题

每一级各有 **5 个子设置**（**一级标题只有 4 个** —— 它没有父级编号，不显示「编号层级间隔符」）：

| 子设置 | 说明 |
| --- | --- |
| **跳过编号** | 打开后该等级标题**不写编号**，但仍占号，下面的子标题照常编号。后面的下拉框决定旧编号怎么办：`不删除旧编号`（默认，整级不动）/ `尝试删除旧编号`（把已有的旧编号删掉再重命名，例如 `## 1.2、 二级标题` → `## 二级标题`）。 |
| **编号序列** | 本级序号本身的写法，一至六级可以各用各的。后面的下拉框决定编号怎么接：`继承父标题编号`（默认，接在父级后面）/ `重新编号`（本级从 1 开始、不带父级前缀）。**一级没有第二个下拉框** —— 没有父级，谈不上继承。 |
| **前后缀括符** | 包在编号外面的括号，锁定在 `无` `()` `（）` `<>` `「」` `【】` 里选。 |
| **编号层级间隔符** | 本级编号与父级编号之间的分隔符，锁定在 `无` `.` `-` `_` `:` `~` 里选。**一级标题不显示这一项。** |
| **编号尾缀** | 本级编号与标题内容之间的字符，选项同全局尾缀，**仅在全局尾缀选 `无` 时生效**（全局选了符号 → 本行整行不可编辑）。 |

### 编号序列

| 选项 | 效果 |
| --- | --- |
| `1, 2, 3, 4…` | 阿拉伯数字 |
| `I, II, III, IV…` | 罗马数字（贪心算法：`4` → `IV`、`1990` → `MCMXC`） |
| `一, 二, 三, 四…` | 汉字数字（`10` → `十`、`101` → `一百零一`、`10000` → `一万`、`10001` → `一万零一`） |
| `壹, 贰, 叁, 肆…` | 大写汉字数字（`10` → `拾`、`11` → `拾壹`） |
| `a, b, c, d…` | 小写字母，超过 `z` 回到 `a` |
| `A, B, C, D…` | 大写字母，超过 `Z` 回到 `A` |

每级各选各的，拼起来就是完整编号。例如一级罗马 + 二级汉字 + 三级大写汉字：

```md
# I 甲
## I.一 乙
### I.一.壹 丙
```

### 让某一级从 1 重新开始：`重新编号`

二~六级的「编号序列」那一行还有第二个下拉框：

- **继承父标题编号**（默认）—— 就是原来的行为，编号接在父级后面。
- **重新编号** —— 本级从 `1` 开始、**不带父级前缀**。比它深的级别仍然拿它当父级，照常往下拼。

例如四级选「重新编号」：

```md
# 1 一级标题
## 1.1 二级标题
### 1.1.1 三级标题
#### 1 四级标题        ← 这一级重新从 1 开始
##### 1.1 五级标题     ← 仍然接着四级排
###### 1.1.1 六级标题
```

四级、五级都选「重新编号」：

```md
# 1 一级标题
## 1.1 二级标题
### 1.1.1 三级标题
#### 1 四级标题        ← 从 1 开始
##### 1 五级标题       ← 也从 1 开始
###### 1.1 六级标题    ← 接着五级排
```

**跳级时往上找最近的父级**：如果文里没有四级 / 五级标题，六级就往上找到三级当父级 →
`###### 1.1.1.1 六级标题`。

### 恢复默认设置

设置面板**最下面一行、靠右**的按钮（带 ↺ 图标）。点了会**弹窗确认**（`是否要恢复默认设置？`，
确定在左、取消在右），确认后把所有设置恢复成默认值 —— 等同于刚装好插件、还没动过任何选项的状态。

**语言不在重置范围内**：它是界面偏好，重置后保留你当前的选择（否则面板会在你点完的瞬间整个变成另一种语言）。

### 让某个标题不被碰：`%%skip%%`

在标题的**下一行**写 `%%skip%%`，这个标题就完全不动 —— 不改、不删原有编号、也不占号，当它不存在。其余标题照常编号。「重置标题编号」同样会跳过它。

想让它的**子标题也一起跳过**，打开设置里的「子标题是否继承父标题的跳过注释」。

> 例外：如果同时把那个选项后面的下拉框选成 `尝试删除旧编号`，带 `%%skip%%` 的那一行**自己的旧编号也会被删掉**（选默认的 `不删除旧编号` 则不会）。

````md
## 手工维护的章节
%%skip%%
````

## 重置标题编号

`重置当前笔记标题编号` 会把标题里的编号整段去掉：

| 原来 | 按一次 |
| --- | --- |
| `#### 3.1.1.1 (1) 测试四级标题` | `#### 测试四级标题` |
| `## 2.2 二级标题 ` | `## 二级标题 ` |
| `## 120、第六十节`（本篇标题够多时） | `## 第六十节` |
| `# 一级标题` | 不动（没有编号） |

它和「编号前尝试去除旧编号」是**同一套算法、同一份实现**：从左往右认编号、一次剥干净；认出来的编号再过
「不含非数字中文 / 不含连续两个英文字母（规范罗马数字除外）/ 数字不超过 100 阈值」等校验（细则见上面「编号前尝试去除旧编号」一节）。

**一次剥干净，不用按多次。** 分层编号（`#### 3.1.1.1 (1) 测试四级标题`）一次就能剥成 `#### 测试四级标题`。
好处是可预测；也不需要迭代 —— 当年「反复切」会在真实笔记上误删（见 CHANGELOG 1.2.2 的实测数据）。

## 与 Obsidian 官方「重命名小标题」的关系

本插件**没有**替换官方命令，你的 `编辑器: 重命名当前小标题` 照旧可用。

但要如实说明一件事：**官方那个命令是纯交互式模态框**（一次改一个标题、必须人工输入确认），没法用于自动编号。所以插件编号时是复刻官方的副作用链路 —— 改标题行 + 用 Obsidian 自己的链接更新接口同步全库链接 + 同步 Canvas 嵌入卡片。

## 已知限制

1. **「跳过编号」打开的那一级不写编号**，但仍占号。要不要顺手删掉旧编号由同一行后面的下拉框决定（默认不删）。
2. **两条「去旧编号」都要求编号后面有分隔**。认不出编号（编号后既没有空格、也没有 `、` `-` `)` `_` `>` `」` `）` `】` `』` 等尾符，也没被括符包住）时不动手。
   **一个例外**（2026-09-28 起）：编号是**多段纯阿拉伯、且只用 `.` / `-` 分段**时，可以直接跟中文正文 —— `1.1定义合法标识符规则`、`2.1时间进度安排` 能剥。单段不开口子（`5总结` 仍是正文）；`12:30出发`（`:` 分段）、`3~78位`（`~` 分段）、`1-a-b标题`（含字母段）也都不走这条例外。
   ⚠️ 缺了这条例外时会**剥半截**：`1.4参考资料` 会退取更短的 `1.` 当编号 → 剥成 `4参考资料`（静默改坏标题，比不剥更糟）。
3. **序号上限 99**（2026-09-28 起）：编号里任何一段超过 99 就不算编号 —— `## 120、第六十节`、`## 2024 年度总结` 都会整条不动。（插件本身从 1 开始编号，不会产出 0 或三位数，所以 `## 一百、 标题`、`## 零、 标题` 也不认。）
4. **一次只剥一层编号**（2026-09-28 起）：`## 3.1.1.1 (1) 标题` 会剥成 `## (1) 标题`（剥掉 `3.1.1.1`，留下 `(1)`）。堆叠的编号多跑几次即可。旧行为会把两段一起吃，但它的判据复杂到说不清为什么。
5. **判据只问一件事：这段前缀是不是插件自己会生成的编号**（2026-09-28 起）。所以「看起来像编号但插件生不出」的写法不认 —— 例如 `;` / `：` / `~` 后面直接接标题（它们是**分隔符**候选，不是尾缀）。同理**带前导零的写法也不认**：插件产出的是 `4、` 而不是 `04、`，所以 `04、系统测试`、`001-查询…` 一律不动。
6. **有四类「原理上不可分」的形态被主动放弃**（宁可漏认，不可误删）：
   - `1标题` —— 尾缀选「无」且「不加空格」时，编号与正文直接粘连；与「正文以短数字开头」同形。
   - `C-标题` / `I-V` / `V-a` —— **编号核以「单个字母 + 连字符」开头**（字母编号 + `-` 尾缀不加空格，或字母编号 + `-` 间隔符）；与连字符词 `a-b` / `T-恤` 同形。⚠️ 只有**核开头**这一处放弃：编号核**中间**的「单字母 + 连字符」照常认（`肆.V-a 标题` 能正常剥成 `标题`）。
   - `4.jsp` / `5.js` —— **「数字 + `.` + 纯小写拉丁词」**（2026-09-28 加）。与「阿拉伯编号 + `.` 尾缀不加空格」同形。只要 `.` 后面出现中文就照常认（`3.springboot配置` 能剥成 `springboot配置`）；带空格的 `1. 命名规则` 也照常剥。
   - `120、第六十节` —— 序号超过 99（见第 3 条）。
   遇到这种情况，把该级「编号前尝试去除旧编号」关掉，或给那个标题下一行加 `%%skip%%`。
7. **同步别的笔记里的链接，依赖 Obsidian 内部接口**。取不到时**插件会停手**：一行标题都不改，并提示
   `Heading Guard:无法同步链接，标题已停止更改` —— 宁可标题停在原地，也不留下指向旧标题名的链接。
   自动编号下这条提示**只弹一次**（免得刷屏），接口恢复后再出问题才会重新提示。
   注意它只挡得住「接口不在」；**接口还在但调用后没真正生效**（静默失效）这种情况插件无法察觉，
   那时标题会照常改、**别的笔记里**的链接不会跟着走 —— 这一点如实说明。
   本文档**自己**里的链接不依赖那个接口（与标题改动写在同一次编辑里），所以那一条永远跟着走。
8. **同名标题**：不同笔记里可能有同名标题，插件靠链接的解析结果判断归属，只改真正指向本文档的那些链接。
9. **只处理 Markdown 编辑器里的当前笔记**。阅读视图、Canvas、大纲面板不参与。
10. **光标停在标题行上时这一轮不编号**（防打断输入）。光标移到别处后，下一次触发就会补上。
    想立刻编，用手动命令；刚切进笔记时也不受此限。
11. **数字上限的阈值是固定的 100**，不随笔记规模动态调整。标题总数少于 100 的笔记里，
    正文以三位以上数字开头的标题（如 `453  Shelvin Mack`）一律不会去编号 —— 这是宁可少删、不可误删。
12. **标题里出现 `/` 或 `\` 时整条不动**（2026-09-28 起）。这类标题多半是路径 / 命令 / 表达式
    （`1、`./`和`sh`的区别`、`2、银行卡密码修改/重置(5144)`），宁可漏认也不冒误删风险。
    代价：编号本身没问题、只是正文含斜杠的标题也不会去编号。想编就先手动把斜杠挪出标题，或给该级关掉去旧编号。

## 兼容性与性能

- 最低版本 `1.4.0`，桌面端与移动端均可（`isDesktopOnly: false`）。
- 无任何外部依赖，无构建步骤，`main.js` 是单文件。
- **实测开销（40 个标题的笔记，本机）**：兜底复查在标题没变时 **4.2 µs/次**，走完整套编号规划 **7.0 µs/次**。也就是说签名比对只省掉 40%（2.8 µs）—— 按 10 秒一次算，一天省下的时间还不够一次屏幕刷新。仍然保留它，是因为它让「无事可做」的路径**不读编辑器行**、语义也更清楚；真正让体验变好的是「切笔记 / 停手就立刻编号」那两层事件触发，它们空闲时零开销。
- 只有真的出现差异时才写文档，并且只写一次事务。

## 反馈

发现编号不对、链接被改坏、或者想让某条规则更灵活，把**出问题的那几行标题原文**和**你的编号规则设置**一起发出来。
