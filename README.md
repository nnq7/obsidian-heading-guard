# Heading Guard

给 Markdown 笔记的标题自动编号，编号变了还会顺手把指向它的链接改对。

```md
# 1 项目目标
## 1.1 总体原则
### 1.1.1 为什么
## 1.2 边界
# 2 实现
```

一至六级可以各设各的规则（数字写法、括号、层级间隔符、尾缀）；不想被碰的标题，下一行写 `%%skip%%` 就行。

## 安装

**手动安装（当前可用）**

1. 下载 `manifest.json`、`main.js`、`styles.css`。
2. 在仓库里建一个文件夹 `.obsidian/plugins/heading-guard/`，把这三个文件放进去。
3. 重启 Obsidian → 设置 → 第三方插件 → 关闭「受限模式」→ 启用 **Heading Guard**。

**从插件市场**：设置 → 第三方插件 → 浏览 → 搜索 `Heading Guard`。搜不到就是还没上架，走上面的手动安装。

## 三步用起来

1. 设置 → 第三方插件 → **Heading Guard** → 打开 **开启自动编号**。
2. 打开任意一篇有标题的笔记，停手约 1 秒 —— 编号就写好了。按一次 `Ctrl+Z` 能整体回退。
3. 不想等它自动触发：`Ctrl+P` → **立即编号当前笔记**。

> 自动编号**默认关闭**，装好不会动你的笔记，要你先打开它才生效。
> 拿不准规则改对没有，看设置面板里的 **样式预览** —— 它按当前规则实时显示六行样例。

## 两个命令

| `Ctrl+P` 里搜 | 作用 |
| --- | --- |
| **立即编号当前笔记** | 立刻编号一次。已经编好的笔记重复跑也不会有变化。 |
| **重置当前笔记标题编号** | 去掉标题上的编号，只留标题文字。 |

手动跑完会弹提示 `N条标题已自动编号`；如果链接跟着改了，再弹一条 `更新M个文件中的N条链接`。
自动触发（切笔记 / 停手 / 兜底复查）是**静默**的，只有你主动跑命令时才弹提示。

## 常见用法

### 1. 编号想要顿号：`# 1、 一级标题`

设置 → **全局编号尾缀**，尾缀字符选 `、`，右边选「尾缀后加空格」。

| 想要的效果 | 尾缀字符 | 尾缀后 |
| --- | --- | --- |
| `# 1 一级标题` | `无`（默认） | — |
| `# 1、 一级标题` | `、` | 加空格 |
| `# 1、一级标题` | `、` | 不加空格 |

### 2. 换数字写法：罗马 / 汉字 / 字母

展开 **一级标题** ~ **六级标题**，改里面的 **编号序列**，每级可以各选各的。

| 选项 | 效果 |
| --- | --- |
| `1, 2, 3, 4…` | `# 1 甲` |
| `I, II, III, IV…` | `# I 甲` |
| `一, 二, 三, 四…` | `# 一 甲` |
| `壹, 贰, 叁, 肆…` | `# 壹 甲` |
| `a, b, c, d…` | `# a 甲` |
| `A, B, C, D…` | `# A 甲` |

### 3. 让某一级从 1 重新开始

二~六级的 **编号序列** 那行还有第二个下拉框：

- **继承父标题编号**（默认）—— 接在父级后面，`1.1.1` 这样。
- **重新编号** —— 本级从 `1` 开始，不带父级前缀。

例如四级选「重新编号」：

```md
# 1 一级标题
## 1.1 二级标题
### 1.1.1 三级标题
#### 1 四级标题        ← 这一级从 1 开始
##### 1.1 五级标题     ← 仍然接着四级排
```

### 4. 某个标题不要编号：`%%skip%%`

在标题的**下一行**写 `%%skip%%`，这个标题就完全不动（不改、不删编号、也不占号）：

````md
## 手工维护的章节
%%skip%%
````

想让它的**子标题也一起跳过**，打开 **子标题是否继承父标题的跳过注释**。

### 5. 去掉已有的旧编号

- 只想去这一次：`Ctrl+P` → **重置当前笔记标题编号**。例：`#### 3.1.1.1 (1) 标题` → `#### (1) 标题`。
- 想以后每次编号都顺手去掉：打开 **编号前尝试去除旧编号**。

这两件事是**同一套规则、每次只切一刀**，所以分层编号要多按几次才干净 —— 这是故意的：宁可多按一次，也不冒误删标题文字的风险。

### 6. 改乱了想还原

设置最下面一行靠右的 **↺ 恢复默认设置**，点了会弹窗「是否要恢复默认设置？」（确定在左、取消在右）。确认后回到刚装好、没动过任何选项的状态；**语言不受影响**。

## 几句提醒

- 打开「跳过编号」的那一级不写编号，但仍占号。
- 「去旧编号」是猜的：标题正文本身以「短数字 + 空格」开头时可能被误删。补救：关掉该级 **编号前尝试去除旧编号**，或给这个标题加 `%%skip%%`。
- 手写的序号不会被自动当成编号：`## 二、设置界面` → `## 1 二、设置界面`。
- 只处理**当前打开的那篇 Markdown 笔记**。阅读视图、Canvas、大纲面板不参与。
- 万一取不到 Obsidian 的链接更新接口，插件会**停手**：一行标题都不改，并提示 `Heading Guard:无法同步链接，标题已停止更改`。
