# Heading Guard

给 Markdown 笔记的标题自动编号，编号变了还会同步双链。

一至六级标题可以各设各的规则（数字写法、括号、层级间隔符、尾缀）；
不想被碰的标题，可以紧挨着下一行写 `%%skip%%` 就行。
如果某一级别标题都不想改变，可以打开`跳过编号`按钮

## 安装

1. 下载 `manifest.json`、`main.js`、`styles.css`。
2. 在仓库里建一个文件夹 `.obsidian/plugins/heading-guard/`，把这三个文件放进去。
3. 重启 Obsidian → 设置 → 第三方插件→ 启用 **Heading Guard**。

**从插件BRAT**安装：设置 → 第三方插件 → BART 

## 两个命令

| `Ctrl+P` 里搜 | 作用 |
| --- | --- |
| **立即编号当前笔记** | 立刻编号一次。 |
| **重置当前笔记标题编号** | 去掉标题上的编号，只留标题文字。部分格式无法识别，需要手动处理 |
