# Heading Guard

[English](README.md) | 简体中文

Obsidian 笔记标题自动编号插件：一至六级标题按你的规则加编号，编号变化时 `[[笔记#标题]]` 双链会一起同步更新。

> 完全离线运行：不发起任何网络请求、不收集任何遥测、不读写仓库以外的文件。

## 功能

- 一至六级标题分别设置编号序列（阿拉伯数字、大小写罗马数字、汉字等）、前后括符、层级间隔符与编号尾缀；
- 某一级不想编号，打开该级的 `本级不编号` 即可——层级结构保留，子标题仍按规则编号；
- 临时跳过某个标题：在标题的**下一行**写 `%%skip%%`；连它下面的子标题一起跳过写 `%%skips%%`；
- 单篇笔记可用 frontmatter 指定样式：`heading-guard: on` / `heading-guard: 方案A` / `heading-guard: on|方案A`；
- 父级标题缺失、或级别跳着写时，子标题默认按级别补齐编号，也可以改成继承上一级的样式；
- 自定义样式可存成命名方案，之后一键切换；
- 只在你改过标题之后才写入，不会反复重写没变化的笔记。

> 推荐一个标题重命名插件，比右键标题选择重命名更加便捷：<https://github.com/PlayerMiller109/obsidian-keep-headings>

## 安装

**社区插件市场（推荐）**：设置 → 第三方插件 → 浏览 → 搜索 `Heading Guard` → 安装 → 启用。

**手动安装**：

1. 下载 `manifest.json`、`main.js`、`styles.css`；
2. 在仓库里建一个文件夹 `.obsidian/plugins/heading-guard/`，把这三个文件放进去；
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **Heading Guard**。

**通过 BRAT 试用新版本**：先安装并启用 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，在其设置里 `Add Beta plugin` 填入 `nnq7/obsidian-heading-guard`。

## 两个命令

| `Ctrl+P` 里搜    | 作用                              |
| -------------- | ------------------------------- |
| **立即编号当前笔记**   | 立刻编号一次；手动执行会先弹出编号前后的对照，确认后才写入   |
| **重置当前笔记标题编号** | 去掉标题上的编号，只留标题文字。部分格式无法识别，需要手动处理 |

## 设置说明

- **开启自动编号**：总开关，默认关闭。关闭时两个命令仍然可用。
- **编号前尝试去除旧编号**：编号前先尽量剥掉标题里已有的编号（支持的格式有限，认不出来就原样保留）。
- **自动编号的作用范围**：`所有笔记` / `仅已启用的笔记`。后者只处理 frontmatter 里写了 `heading-guard: on`（含 `on|方案名`）的笔记；两个命令不受此限制。
- **检测间隔**：兜底轮询的秒数，范围 5~60。
- **排除文件夹**：一行一个文件夹路径（相对仓库根目录），这些文件夹里的笔记不参与自动编号。
- **样式预览**：按当前规则实时预览；选「阶梯式编号」时会并排显示两种编号方式的对照。
- **保存标题样式**：把当前各级设置存成一个命名方案，之后一键套用、切换或删除。
- **父级别缺失或级别不连续时编号方式**：父标题缺失、或被 `%%skip%%` 跳过时，子标题是补齐层级（如 `1.1`）还是整体上移一级。
- **各级标题**：每一级都能单独设编号序列、前后括符、层级间隔符、编号尾缀，以及是否 `本级不编号`。

界面语言跟随 Obsidian 自己的语言设置（设置 → 关于 → 语言）：简体中文用简体、繁体中文用繁体，其它语言一律英文。

## 跳过编号与单篇笔记样式

### 跳过某个标题：`%%skip%%` / `%%skips%%`

在标题的**下一行**写跳过注释（写在标题同一行不生效）：

```md
# 一级标题
%%skip%%
```

| 写法          | 作用                 |
| ----------- | ------------------ |
| `%%skip%%`  | 只跳过这一个标题           |
| `%%skips%%` | 跳过这个标题，以及它下面所有的子标题 |

- 被跳过的标题保持原样：不加编号，原有的编号也不会被改动；
- 跳过父标题后，子标题按「父级别缺失或级别不连续时编号方式」处理（默认补齐层级，如 `1.1`）；
- 那一行里只要包含这个标记就命中，可以连同别的文字一起写（例如 `%%skip%% 稍后再补`）。

### 给单篇笔记指定样式：frontmatter

在笔记的 frontmatter（属性）里加一项 `heading-guard`，三种写法：

- `heading-guard: on` —— 这篇笔记**开启自动编号**，样式用插件设置里那一套；
- `heading-guard: 方案A` —— 这篇笔记使用已保存的样式「方案A」，但**不**开启自动编号；
- `heading-guard: on|方案A` —— 开启自动编号，并且使用已保存的样式「方案A」。

> 方案名要和你**保存过**的样式一致。范围是「仅已启用的笔记」时，只有写成 `on` 或 `on|方案A` 才会自动编号 —— 光写方案名不开启。

## 数据与隐私

- **不联网**：不发起任何请求，没有更新检查，也没有统计上报；
- **无遥测**：不记录任何使用行为，也不上传任何数据；
- **不越界**：只读写当前仓库里的 Markdown 文件，以及插件目录下自己的 `data.json`，不访问仓库以外的文件；
- **不需要账号、不收费**：全部功能免费可用。

## 常见问题

**编号没生效？** 先确认「开启自动编号」已打开；若范围是「仅已启用的笔记」，笔记 frontmatter 里必须有 `heading-guard: on`。

**为什么某个标题没被编号？** 三种可能：笔记在「排除文件夹」里、该标题下一行写了 `%%skip%%` / `%%skips%%`、或者该级别打开了 `本级不编号`。

**`%%skip%%` 写在哪？** 必须写在标题的**下一行**；写在标题同一行不生效。

**改了标题，双链没跟着变？** 被跳过、不编号的标题不参与改写；同步失败时会提示「无法同步链接」，此时标题保持原样。

**改了 Obsidian 的语言，插件界面没变？** 插件语言跟随 Obsidian，切换语言后 Obsidian 会要求重载；重载后即生效。
